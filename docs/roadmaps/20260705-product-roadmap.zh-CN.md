## 身份与北极星（详见[纲领](../charter.zh-CN.md)）

- **身份**：Glaux 首先是**环境 / 底座**，不是一个智能体。通用智能体是大脑 / 引擎（BYO、可配置）；Glaux 是身体 + 世界（眼、手、器械、律法、记忆）。**智能体只是跑在环境里的租客。**
- **引擎立场（已拍板）**：两者兼有——用户可自配 API / 模型，同时提供自有参考智能体。谁当引擎不动摇根基，因为飞轮与验证长在环境里。
- **北极星**：成为生物医学影像洞察的 agent-native 环境——任何智能体跑在其上，把任意模态图像变成可验证、可复现的洞察。
- **一句话**：别在推理上跟通用 agent 卷；建它推理所在的**环境**。

## 护城河判据（动工前先过一遍；详见[纲领](../charter.zh-CN.md) §六）

> 只建"模型越强越值钱"的资产；模型变强会让它作废的，是负债，做够能用即可。**每份工作必须加深「环境四层」之一。**

| 建的是… | 对应环境层 | 判定 |
| --- | --- | --- |
| 薄 NL→脚本 wrapper / 提示词链 / 硬编码流程 | —（让 agent 更聪明，是引擎厂商的活） | ❌ 负债——最小化 |
| 跨模态解码 → 统一可计算表征 | 表征层（眼） | ✅ 护城河 |
| 分割 / 测量 / 重建 + 单位校准 + 模态护栏 | 动作层（手 + 器械） | ✅ 护城河 |
| ground-truth / provenance / 可重跑 / 审计 | 验证层（律法 + 裁判） | ✅ 护城河 |
| 已验证轨迹 + 人工校正 + 领域先验（飞轮） | 记忆层 | ✅✅ 最强，复利 |

## 执行铁律：愿景要宽，楔子要窄

愿景是"跨模态的 insight agents"；**首个楔子只打一个模态、一类工作流**，把飞轮和验证底座跑通，再横向扩模态。创业公司死于过早铺开执行面，不死于愿景太大。

## 远景 · 远期目标（超出当前四步，也超出当前边界）

> 近期严守「研究洞察，非临床决策」的红线（合规原因）；下面是**远期**方向——方向明确，但不排期、不承诺。

- 🟩 **平台化与分销**：Glaux-as-MCP-server，让通用 agent 经 MCP 调用已验证动作空间——化威胁为分销。
- 🟩 **可复现研究工作流**：面向发表 / IRB / 脱敏数据，把「研究非临床」做成可信资产。
- 🟨 **跨任务记忆**：多任务 / 有状态的研究项目记忆，跨任务复用飞轮。
- 🟩 **全模态覆盖**：从 1–2 个验证场景扩到显微 / 病理 / 超声 / CT…，真正兑现「模态无关」。
- 🔭 **辅助决策（远期北极星）**：当环境足够成熟、且跨过监管门槛（SaMD：FDA / NMPA）后，自然的演进是从「洞察」走向**辅助决策**——把可验证的洞察接入决策支持。**这不改变近期边界**：近中期只做研究洞察；辅助决策是远景，且必须先建成前四层环境、再谈决策。
