## 北极星与双层模型

- **上层（用户看到的）**：一个 agent，给它研究目标，它规划、执行、**自我验证**、迭代、跨实验记忆，交回可验证的洞察。
- **下层（护城河）**：已验证的领域动作空间 + 可复现 / provenance 底座 + 复利的已验证知识飞轮 + 信任 / 分销。
- **一句话**：别在推理上跟通用 agent 卷；占住它推理所在的**环境**、和它学习所依赖的**已验证数据**。

## 护城河判据（每个条目动工前先过一遍）

> 只建"模型越强越值钱"的资产；模型变强会让它趋近于零的，是负债，做够能用即可。

| 建的是… | 判定 |
| --- | --- |
| 薄 NL→脚本 wrapper / 提示词链 / 硬编码流程 | ❌ 负债——最小化投入 |
| 已验证领域动作空间（解码器 / 分割器注册表 / 带单位校准的测量原语 / 模态先验护栏） | ✅ 护城河 |
| 验证 + 可复现 + provenance 底座 | ✅ 护城河 |
| 已验证知识飞轮（意图→流程→结果→**人工校正**→provenance） | ✅✅ 最强，复利 |

## 执行铁律：愿景要宽，楔子要窄

愿景是"跨模态的 insight agents"；**首个楔子只打一个模态、一类工作流**，把飞轮和验证底座跑通，再横向扩模态。创业公司死于过早铺开执行面，不死于愿景太大。

## 阶段

标签：🟩 = 护城河资产 · 🟨 = 必要但非壁垒 · ⬜ = 负债，最小化

### 阶段 0 · 地基（进行中）
- [ ] 🟨 敲定新仓库工程规范——**把"可诊断的失败 / 可重跑 / 审计轨迹"写进规范**（验证底座从第一天起就是一等目标）
- [ ] 🟨 迁移计划：从荧光显微原型移植可复用核心（解码 · 分割 · 测量）
- [ ] 🟩 定义"已验证产物"的数据契约：结构化结果 + provenance + 校正回流的最小 schema

### 阶段 1 · 第一条 NL→分割闭环（首个楔子：荧光显微一类形态计量任务）
- [ ] 🟩 端到端闭环：研究目标（自然语言）→ agent 规划 → 分割 → 测量 → **验证** → 结构化洞察
- [ ] 🟩 **飞轮入口**：人工校正被结构化捕获、可回流——这是数据资产的种子，不是 UI 细节
- [ ] 🟩 provenance 默认产出：每个结果可重跑、可审计（对标 Agentic-J 的"状态账本"，但结构化产物优先）
- [ ] 🟨 集成成熟分割模型（Cellpose-SAM / micro-SAM / StarDist），**不自研 SOTA 分割器**
- [ ] 🟩 建立首个领域评测集（用真实任务 + 校正数据），正面对着约 58% 可靠性天花板做

### 阶段 2 · 证明"模态无关"（定位命根子）
- [ ] 🟩 至少一个非荧光模态的最小案例（超声或 CT 的一次分割 + 测量），验证策略注册表跨模态成立
- [ ] 🟩 把"模态先验 / 护栏 / 单位与尺度校准"沉淀进动作空间

### 阶段 3+ · 平台化与分销（方向）
- [ ] 🟩 Glaux-as-MCP-server：让通用 agent 经 MCP 调用已验证动作空间——化威胁为分销
- [ ] 🟩 面向发表的可复现工作流（IRB / 脱敏数据），把"研究非临床"做成可信资产
- [ ] 🟨 多任务 / 有状态的研究项目记忆（跨任务复用飞轮）

## 需要盯的信号（竞争分析会过期，建议每季度刷新）
