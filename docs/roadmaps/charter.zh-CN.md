# Glaux 纲领 · Charter

## 一、名字与宗旨

- **名字**：Glaux，中文名小鸮。γλαύξ 是古希腊语的小鸮，雅典娜的鸟，在暗处也看得清。
- **宗旨**：将视觉转化为洞见（*Turning sight into insight*）。
- **洞见**：不是模型随口给出的描述，而是可验证、可复现的结论。
  - 说得清依据在图像哪一处、视频哪一帧、声音哪一段。
  - 说得清经过了哪些操作。
  - 重跑，结果一致。

## 二、领域

图像与视频，多种模态、多种格式。

| 类别 | 模态（成像方式） | 数据形态 | 常见格式 |
| --- | --- | --- | --- |
| 自然图像与视频 | 可见光拍摄（照片、摄像） | 2D 图像、视频 | PNG、JPEG、WebP；MP4 等 |
| 显微与病理 | 明场、荧光显微；病理全切片 | 2D / 多通道 / z-stack、延时序列、超大切片 | TIFF；SVS、NDPI、MRXS 等 |
| 医学影像 | 超声、X 线、CT、MRI 等 | 2D、动态序列（如超声 cine）、3D 体数据 | DICOM、NIfTI；PNG、TIFF |

- **格式**决定怎么读文件。
- **模态**决定怎么解码、用什么单位与尺度、什么算对。
- **视频**中的帧、时间、轨迹与事件同样是分析对象；视频自带的音频与画面共享同一条时间轴，同属观测内容。

## 三、边界

- Glaux 负责从图像与视频到理解，再到可计算的表征。
- 拿表征做决策与规划，由用户在 Glaux 之上自建。
- 生物医学方向（显微与病理、医学影像）只做研究：脱敏数据的回顾性研究在内，受监管的临床诊断不做。

## 四、核心信念

- 通用智能体的推理、规划与看图能力会持续变强并商品化，多模态模型已经能描述照片、切片和视频。
- 描述画面越来越便宜，但以下三样不会随模型变强自动出现：
  - 带单位的测量；
  - 说得清出处的结论；
  - 能原样重跑的过程。
- **持久的价值在于让图像与视频洞见得以发生的环境，而这正是通用智能体顾不到的。**

## 五、身份：Glaux 是 harness

> **智能体 = harness + 模型**

- **模型**负责推理：理解、规划、决定下一步。它由用户自带、可以替换，正在商品化。
- **harness**（下文也称环境）是模型运行的地方：决定模型能看到什么、能做什么、怎样算对，以及跨任务积累下什么。

本仓库就是这个 harness，是模型在图像与视频分析中的运行时环境。无论接入哪个模型，Glaux 都提供同一个环境，由第六节的四个要素构成。

## 六、环境的四个要素

借用强化学习对环境的定义：模型是策略，Glaux 是它交互的环境。

| 要素 | 回答的问题 | Glaux 里是什么 |
| --- | --- | --- |
| **观测空间** | 模型看到什么 | 读取多种模态、多种格式的图像与视频，带上物理语义（像素间距、通道、帧时间、采样率）；决定给模型呈现哪一部分（切块、抽帧、裁剪、叠加，以及与画面对齐的音频区间） |
| **动作空间** | 模型能做什么 | 分割、测量、跟踪、重建等工具，集成专用模型，带单位、尺度与护栏 |
| **验证器** | 怎样算对 | 结论可溯源到帧与区域、可原样重跑、多种方法相互印证、人工复核；有标准答案时计算指标 |
| **回合与轨迹** | 积累下什么 | 一次分析是一个回合；经过验证的轨迹与人工校正沉淀为案例库，供后续任务检索、评测与改进 |

验证器首先用于在每次分析中判定结果对错，不一定用于训练模型。四个要素就是路线图要建的东西。

## 七、决策过滤器

动工前问三个问题：

- **更强的模型会让它作废吗？** 会，就是负债，少投入（薄 wrapper、提示词链、硬编码流程）。
- **更强的模型会让它更值钱吗？** 会，就是护城河，值得投入。
- **它加深了环境四个要素中的哪一个？** 答不上来，多半是在让智能体更聪明，那是模型厂商的事。
