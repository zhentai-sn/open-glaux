# 篮球视频理解基准调研：BasketballBench / BasketballSkills

> **用途**：为视频分析特性的首个落地场景（篮球比赛视频）提供公开基准与方法参照。
> **日期**：2026-09-25 · **类别**：research（科研）
> **依据**：[纲领](../roadmaps/charter.zh-CN.md) 第六节「观测空间」· [SDD 11 视频理解 harness](../sdd/feats/11-video-understanding-harness/README.md)
> **来源**：arXiv 2608.23435v1（HTML 版正文与表 2、表 5）；上游数据集 arXiv 2607.21267。数字未与 PDF 逐项核对，引用前复核。

---

## 0. 结论

- BasketballBench 是目前覆盖面最全的篮球多模态基准：10 个任务、7,980 题，文本、图像、视频三种模态，数据来自 2025-26 赛季 NBA。
- 论文主张：用少量篮球专用工具组成 agent，比单靠通用多模态模型效果好。BasketballSkills 总分 72.3，最强基线 GPT-5.4 为 65.1。
- 拆开看，大幅领先集中在**需要结构化比赛数据**的题目（Q1、Q2、Q3、Q10，领先 27～59 个百分点），主要靠 SQL 检索官方数据，而不是视觉能力。
- 纯视觉题领先幅度小或落后：Q5 +12.6、Q6 +6.4、Q8 +16.1、Q9 +0.7；Q4 记分牌读取 −6.0，Q7 时间定位 −29.7。
- 所有方法在 Q8（结构化回合事件，Full-Event F1）上都不超过 45.9，这是最难的一项，也是「谁在何时做了什么」的核心。
- 对 Glaux 的含义见第 5 节：可直接借用视频任务（Q5～Q10）做篮球场景的评测参照；时间定位（Q7）与 SDD 11 的证据区间直接对应。

## 2. 数据构成

| 数据 | 规模 |
| --- | --- |
| 转播片段 | 2,501 个回合级（possession-level）片段，取自 BasketEvent 测试集；33 场比赛；1280×720、25 fps |
| 逐回合数据（PBP） | 266 场比赛、43,558 条事件，来自 NBA.com；归一为 10 类事件、6 个投篮区域 |
| 球员资料 | 530 名现役球员的名单与资料、官方头像 |

构建流程：

- 片段与所属比赛、PBP 区间关联。
- 用 Qwen3.6-27B 以 1 fps 识别记分牌，把视频时间映射到比赛时钟。
- 用人工设计的模板从结构化记录生成题目，干扰项取其他实际出现的类别值或相近数值。
- 人工校验：
  - Q4：保留率 66.7%。
  - Q7：790 个目标事件全部人工标注时间戳。
  - Q8：1,000 题中 25.8% 经人工修正。
  - Q9：全部候选人工复核。
  - 其余任务：只做确定性的 schema 校验。

## 3. 任务与结果

| 任务 | 模态 | 题数 | 答案形式 / 指标 | GPT-5.4 | Claude Sonnet 5 | Gemini 3.5 Flash | BasketballSkills |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Q1 篮球知识 | 文本 | 1,200 | 四选一 / 准确率 | 64.6 | 54.1 | 65.9 | **93.3** |
| Q2 比赛形势 | 文本 | 1,200 | 四选一 / 准确率 | 37.7 | 8.1 | 40.2 | **99.2** |
| Q3 球员图像知识 | 图像 | 400 | 四选一 / 准确率 | 47.5 | 36.5 | 36.6 | **87.0** |
| Q4 记分牌读取 | 图像 | 200 | 结构化文本 / 完全匹配 | 93.5 | 92.5 | **94.0** | 88.0 |
| Q5 动作定位 | 视频 | 600 | 六选一 / 准确率 | 57.2 | 23.5 | 41.5 | **69.8** |
| Q6 动作识别 | 视频 | 500 | 四选一 / 准确率 | 85.4 | 55.8 | 78.2 | **91.8** |
| Q7 时间定位 | 视频 | 1,580 | 时间戳 / Acc@1s | **77.5** | 51.3 | 63.2 | 47.8 |
| Q8 回合事件 | 视频 | 1,000 | 结构化事件 / Full-Event F1 | 29.8 | 14.3 | 27.0 | **45.9** |
| Q9 球衣号码识别 | 视频 | 300 | 四选一 / 准确率 | 92.3 | 89.7 | 94.3 | **95.0** |
| Q10 球员视频知识 | 视频 | 1,000 | 四选一 / 准确率 | 48.7 | 45.4 | 53.0 | **83.7** |
| 总分 | — | 7,980 | — | 65.1 | 46.7 | 59.5 | **72.3** |

- 论文指出：所有通用模型的 Q6 得分都低于 Q9，说明「球员与事件的对应」比单独识别号码更难。
- 论文未评测 Qwen3.8-Omni-Flash 等原生音画模型，也未使用音频。
- 评测协议：视频按 2 fps 抽帧输入（球衣号码工具例外，均匀取 8 个裁剪块）；输出须满足各任务的 schema，不合格即判错。

## 4. BasketballSkills 方法

控制器为 DeepSeek-V4-Flash，接收问题、原子工具库和技能目录。它先选技能，再按技能规定的工具顺序调用，每次调用都经过轻量校验器，最后生成答案。

### 4.1 原子工具（8 个）

| 工具 | 实现 |
| --- | --- |
| 人脸识别 | 开源人脸识别库，与官方球员头像库比对 |
| 球衣号码识别 | Qwen3.5-9B + 任务提示词 |
| 记分牌读取 | Qwen3.5-9B |
| 球员与球跟踪 | SAM 3 + 微调 RF-DETR |
| 轨迹级事件检测 | PlayNet |
| 投篮区域分类 | PlayNet + 六分类头 |
| 事件时间定位 | Qwen3.5-9B |
| 结构化知识检索 | SQL 数据库（18 张表），固定查询接口 |

### 4.2 技能（4 个）

技能规定工具顺序、证据绑定方式和停止条件。

| 技能 | 工具链 |
| --- | --- |
| 基于人脸的知识检索 | 人脸识别 → 知识检索 |
| 投篮分析 | 跟踪 + 事件检测 → 投篮区域或球衣号码 |
| 带身份的逐回合生成 | 跟踪 + 事件检测 → 球衣号码 → 序列化事件 |
| 基于事件的球员知识检索 | 跟踪 + 事件检测 → 球衣号码 → 知识检索 |

### 4.3 消融与失败分析

- 技能消融（表 5）：视频题的平均工具调用次数减少 16.74%，准确率基本不变（有技能 72.34%，无技能 72.76%）。技能的作用是降低成本，不是提升精度。
- 失败模式：
  - 不必要的工具调用，且该工具返回了错误结果。
  - 上游检测错误沿工具链传播到身份对应环节。
  - 球员与事件的对应仍是薄弱点。

## 5. 对 Glaux 的含义

| 维度 | 观察 | 与 Glaux 的关系 |
| --- | --- | --- |
| 评测参照 | Q5～Q10 是纯视频任务，片段为回合级短视频 | 片段时长在 SDD 11 的单次观察上限（60 秒）以内，可作为篮球场景的定量评测来源；SDD 11 一期不做定量评测（D-15），适合放在业务定性之后 |
| 时间证据 | Q7 以 Acc@1s 评测时间戳，通用模型最高 77.5，工具链反而更低 | 对应 SDD 11 的证据区间；直接衡量「说得清依据在哪一帧」 |
| 优势来源 | 大幅领先来自 SQL 检索官方 PBP 与球员资料 | 场景价值很大一部分在「视频 + 结构化比赛数据」的关联；Glaux 目前没有外部结构化数据源的接入契约 |
| 工具集 | 8 个工具中跟踪、事件检测依赖专门训练的模型（RF-DETR、PlayNet） | 与「harness 做薄、不预写死工具集」的方向存在张力；跟踪在 SDD 11 中已排除 |
| 音频 | 基准与方法都不使用音频 | 解说与现场声音可能帮助定位事件，这是 Glaux 原声观察的差异点，基准无法直接衡量 |
| 模型覆盖 | 未评测原生音画模型 | Qwen3.8-Omni-Flash 在 Q5～Q10 上的表现需要自测 |
