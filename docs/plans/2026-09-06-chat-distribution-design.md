# 基本对话发行包设计与实施计划

用户已确认范围；契约见 [SDD 09](../sdd/feats/09-chat-distribution/README.md)。

采用 chat/full 发行模式：chat 为默认，full 保留已有实验入口。复用会话栏和对话组件，移除首发不可用能力的入口与提示。Agent 在 chat 下始终不给模型领域工具，不依赖 Python 后端。

Docker 使用 Web（静态资源及 SSE 反代）和 Agent（Node + SQLite）两个服务，具名卷保存会话，宿主仅开放回环地址。使用预构建镜像与跨平台启动/停止脚本；不在用户机器编译。保留可本地构建的配置与制作启动包的脚本。Docker 仍需用户预装，首次拉取需要联网，API 连接由用户配置。

实施顺序：
1. 固化 SDD 和设计；不混入已有 run-agent-runtime.sh 改动。
2. 实现发行开关、基本对话界面与领域工具关闭，补模式边界回归。
3. 提供 Docker 构建、反代、Compose、启停与打包脚本。
4. 更新 README 下载/运行和维护者构建说明。
5. 执行前端与 Agent 检查、容器启动/SSE/持久化验证，自审并记录未验收事项。

不自动提交已有工作区改动，不发布镜像或 Release；外部分发前仍需确认实际产物与公开下载验收。
