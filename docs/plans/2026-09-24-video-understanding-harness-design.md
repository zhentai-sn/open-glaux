# SDD 11 视频理解 harness · 一期范围设计

> 本文记录 2026-09-23 至 2026-09-24 的需求讨论，供后续起草 SDD 11。字段、接口、错误码与量化验收门槛须在 SDD 11 中冻结；本文不是实现契约。

## 依据与目标

- [Glaux 纲领](../roadmaps/charter.zh-CN.md)：把视觉转化为可溯源、可复核的结论。
- [SDD 10](../sdd/feats/10-object-convergence/README.md)：提供视频对象、时间轴、取帧参照系与音轨声明；视频理解的观测形状由 SDD 11 承接。
- [全模态模型调研](../researches/20260923-01-tech-omni-model-fit.zh-CN.md)：Qwen 与 MiMo 是待实测的接入候选，厂商接口与定位能力须重新核验。

一期让用户针对一段视频提问，Agent 自主选择要观察的音画区间，给出带原视频证据的回答。验收以视频问答和证据定位为主；允许引用多个片段，不把复杂因果推断列为一期必达能力。

## 一期范围

| 方面 | 已确定的边界 |
| --- | --- |
| 输入 | 浏览器直接上传视频；时长上限 10 分钟，超限明确拒绝导入，不截断。视频单文件字节上限需独立于现有 32 MiB 图像上传上限确定。 |
| 模型 | 用户选择已配置的原生全模态连接。Qwen 与 MiMo 各选一款型号，均须通过真实接口和同一组问答证据用例。型号暂按调研中的 Qwen3.8-Omni-Flash、MiMo-V2.6-Flash，实测前不承诺协议兼容。 |
| 声音 | 源视频含音轨时，问答可同时使用画面、语音与环境声；无音轨时仍可回答视觉问题。 |
| 观察 | Agent 读取视频元数据，自主请求原视频中的短时间区间。后端提供带原声的短视频片段及原视频时间映射；Agent 可再次选择区间观察，无固定的整片上传或预设抽样流水线。 |
| 回答 | 每条可核查的事实结论都引用实际观察过的证据。视觉证据给出原视频时间区间，适用时标出关键帧中的区域；声音证据给出对应音频区间。证据不足时明确说明无法判断。 |
| 复核 | 点击引用可在应用内播放对应的原声短片段，并查看关键帧及适用时的区域标记。 |

## 数据流与职责

1. 导入时检查文件类型、大小、可解码性与时长；合格文件注册为 SDD 10 定义的视频对象。
2. 用户提问后，Agent 读取对象时长、时间基与音轨等元数据，自主决定要观察的区间及后续是否放大或重看。
3. 后端从原文件生成短音画片段，返回原视频起止时间及片段到原视频的时间映射。agent-runtime 根据所选 Qwen 或 MiMo 连接封装其原生音视频请求，并把观测记录为可引用证据。
4. Agent 的最终回答引用观测证据。系统检查对象、时间、区域及证据标识是否有效；界面用证据短片段播放器复核。引用是否支持语义结论，由人工标注样本评测。

同一视频可以按问题观察多个区间。系统限制单次片段大小、观察调用次数及总媒体量；具体限值在真实模型接入试验后由 SDD 11 冻结。到达预算仍缺证据时，Agent 说明无法判断，并保留已观察片段供查看。

## 异常与降级

- 超过 10 分钟的视频拒绝导入并说明上限；不做部分导入。
- 所选连接无法接收原生视频与音频时，视频问答不可用并说明原因。现有普通对话能力不受影响。
- 片段生成、模型调用或证据解析失败时，保留会话与已有证据，给出可理解的失败原因；不静默改用抽帧或语音转写。
- 模型给出无效时间、对象或区域引用时，不把该引用呈现为有效证据。无足够有效证据的事实结论须改为无法判断。

## 一期验收方法

准备人工标注的视频问题集，覆盖纯画面、语音、音画关联、两个片段共同支持的结论、无答案、无音轨、接近 10 分钟上限的视频。Qwen 和 MiMo 使用同一组样本，分别核对答案正确性、证据时间区间、适用时的关键帧区域，以及无证据时的拒答。另验收超时长导入、模型能力不符、片段生成失败与证据引用无效的路径。

两款模型的原生输入格式、调用上限及秒级定位能力仍需实测。量化通过门槛须在实测后、SDD 11 转为 `ready` 前确定。

## 后续范围

- 不在一期接入语音转写回退。后续可由用户配置转写服务；启用时必须明确标记为降级问答，不能把转写当成环境声证据。
- 不在一期建设数小时视频的分层导航、完整视频播放器、实时流媒体、自动跟踪、剪辑或配音。
- Track/Event 等时序发现的持久记录与验证原语，待首次需要验证模型时序判断时单独定契约。

## 起草 SDD 11 前需对齐的契约

- [SDD 10](../sdd/feats/10-object-convergence/README.md) §14、§17 当前把长视频分层导航、帧集合加音频片段列为 SDD 11 目标。起草时需改为本期的 10 分钟短片段观测，并明确长视频导航的后续归属；保留 `streams[]`、`resources.audio`、`ReferenceFrame` 等底座契约。SDD 11 达到 `ready` 前仍不得消费 `resources.audio`。
- [SDD 08](../sdd/feats/08-data-import-first-explorer/README.md) 的浏览器上传单文件上限为 32 MiB。需增加视频独立字节上限、10 分钟时长校验与对应错误语义，避免以图片上限意外拒绝目标视频。
- 确定输入格式与编码受理范围、单次观测片段和总调用预算、两个模型的具体版本与接口、证据时间及区域精度门槛，再把 SDD 11 推进到 `ready`。
