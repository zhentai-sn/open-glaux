A workspace for image and video analysis.

Glaux gives your AI model a workspace to inspect images and video, use analysis tools, and show the evidence behind each result.

Install Glaux ↓View source on GitHub ↗

Runs on your computer · Bring your own model · Apache-2.0

From media to a result you can inspect

Use a single local environment to bring together the source image or video, the tools that act on it, and the record of how a result was produced.

Inspect images and video

Open local files, move through frames, and give a model visual context. Video questions can include time-aligned frame and audio evidence.

Annotate and review

Draw and edit image annotations. Agent suggestions stay reviewable, with their source region available beside the result.

Keep useful examples in Atlas

Collect images and references with descriptions and regions so the agent can consult curated examples during later work.

Inspect tools and runs

Inspect available tools, skills, and subagents. Review request context, model calls, and tool activity turn by turn.

Install once.
Run locally.

On Windows, download the graphical installer. On macOS and Linux, copy one command. The installer checks the downloaded package, prepares its own runtimes, and opens Glaux in your browser.

Need another version or an offline setup? The install guide lists supported systems and options.

Before you install

Do I need to install Node.js or Python?

No. The installer places the Node.js, uv and Python runtimes Glaux needs inside its program directory. It does not require administrator access.

Does Glaux include a model or charge for one?

No. Connect a model provider you choose. Provider pricing and terms depend on that service. Specialized model weights are installed separately when needed.

Where does Glaux keep my data?

By default, in ~/.glaux on macOS and Linux, or %USERPROFILE%\.glaux on Windows. Updating or uninstalling keeps this directory unless you explicitly choose to purge it.

How do I uninstall Glaux?

On Windows, use the Uninstall button in the Glaux desktop control window, or run glaux uninstall to remove the program and keep your data. Run glaux uninstall --purge to remove both.

Can I use it for clinical diagnosis?

No. Biomedical features are for research use and are not intended for clinical diagnosis.
