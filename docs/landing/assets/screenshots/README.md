# 落地页截图

`zh/` 使用应用中文界面，`en/` 使用英文界面，均为亮色主题的实际截图，分辨率为 1440 × 900。WebP 单张不超过 300 KB。

| 文件 | 内容 |
| --- | --- |
| `glaux-overview.webp` | 图像工作区、人工标注与文件栏 |
| `glaux-annotations.webp` | 人工框标注、标签与面积汇总 |
| `glaux-atlas.webp` | 四张内置示例照片组成的图谱案例库 |
| `glaux-context.webp` | 上下文页中的工具目录 |

截图来自隔离的临时工作区，仅加载仓库内 `data/natural` 示例。猫、咖啡杯和狗照片为 CC0 1.0，车辆照片为美国联邦政府作品；作者、来源和哈希见 [示例资产许可表](../../../../data/natural/README.md)。框标注为人工演示，截图未使用私人数据、模型凭据或虚构的模型运行记录。

重新截取时，分别将界面语言设为中文和英文、主题设为亮色。使用全新的浏览器上下文与隔离的会话、上传、图谱和标注目录，等待照片与标注完整显示后截图；更新同名 WebP，并核对语言、许可和体积。
